# Política de segurança

## Versões mantidas

O projeto não publica versões com suporte de longo prazo. A branch `main` é a referência atual; ao relatar um problema, informe o commit ou a versão que você analisou.

## Como relatar uma vulnerabilidade

Use o [canal privado de relato de vulnerabilidades do GitHub](https://github.com/ALRSO85/fingerbridge/security/advisories/new). O envio privado está habilitado neste repositório. Não abra uma issue pública para divulgar uma vulnerabilidade ainda não corrigida.

Para proteger as pessoas, **não envie imagens de digitais, templates biométricos, dados pessoais, identificadores de usuários, logs com dados reais, credenciais, números de série ou licenças de fornecedores**. Use dados sintéticos e descreva o componente afetado, o commit analisado, o impacto e passos mínimos para reproduzir o problema.

Problemas em SDKs ou drivers de terceiros também devem ser comunicados ao respectivo fabricante. Não inclua arquivos desses fornecedores no relato.

## English

Please use [GitHub's private vulnerability reporting](https://github.com/ALRSO85/fingerbridge/security/advisories/new). Do not disclose an unpatched vulnerability in a public issue. Never send fingerprint images, biometric templates, personal data, real-user logs, credentials, vendor serial numbers, or license files. Use synthetic data and include the affected component, commit, impact, and minimal reproduction steps.
